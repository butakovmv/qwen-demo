# Definition of Done (Критерии успешного завершения задачи)

* Составлен `PLAN.md` план написания кода. 
* Код написан. Все трудности, возникшие при реализации и приведшие к изменению изначального плана добавлены в `PLAN.md`.
* Написаны юнит-тесты и API-тесты.
* Линтеры не обнаружили проблем в проекте.
* Код собирается и запускается без ошибок.
* Сформирован отчет по ревью кода (анализ уявзвимостей, потенциальных багов, неоптимальных решений).
* В коде исправлены критичные замечания из отчета по ревью.
* Проходят новые тесты, тесты архитектуры, тесты измененного модуля.
* Документация обновлена (при необходимости).
